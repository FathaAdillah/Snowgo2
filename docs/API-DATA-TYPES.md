# Tipe data dan validasi API v1

Referensi [daftar endpoint dan auth](05-API-CONTRACT.md), [schema](04-DATABASE-SCHEMA.md), dan [state machine](06-BUSINESS-FLOWS.md). Notasi field? opsional, [] array, A/B adalah enum literal, Partial mengambil field opsional dengan sedikitnya satu perubahan. Response schema di bawah merupakan allowlist. Field opsional hanya dikirim bila tersedia dan surface mengizinkan. Identifier pemilik internal, secret, path object, token autentikasi, dan raw provider payload berada di luar projection publik.

## Skalar dan validasi umum

| Tipe | Aturan |
|---|---|
| textN, code, email, phone | Teks UTF-8 trim, 1..N; code 1..80 ASCII [A-Za-z0-9_.-]; email maks 254, canonical case-insensitive; phone E.164 |
| int, qty, money | Integer nonnegative sampai 2.147.483.647; qty 1..10.000 per baris; whole IDR 0..1.000.000.000.000 |
| password, otp, token, hash | Password 12..128 karakter saat create/reset; login menerima 1..128. OTP enam digit sebagai string. Token opaque maksimal 512; hash 64 hex |
| ulid, ref, refs, codes | ULID 26 karakter Crockford; ref adalah nomor entitas bisnis, refs/codes array 1..50 unique; jumlah maksimum mengikuti kebijakan domain |
| date, datetime, bool, term | ISO date, RFC3339 dengan timezone, boolean JSON, FULL atau DEPOSIT |
| RawProviderEvent | Raw request bytes sesuai adapter, maksimum 256 KiB, vendor signature headers dan field event id, reference, timestamp, state dan amount bila payment |
| SettingValue | Sesuai key; inventory.reservation_ttl_minutes 5..180, payment.verification_hold_hours 1..48, returns.window_hours 1..168, orders.auto_complete_hours 48..720, feature flags boolean |
| IntegrationInput | Per domain/provider, base URL dari allowlist; enabled boolean terpisah, mode sandbox/live dan secret_ref opaque; larang host/URL sewenang-wenang |

## Response projections

Field list di bawah memakai snake_case. Field status, amount, date, media dan refs mengambil tipe yang sama seperti input/schema. Admin summary memakai id numerik untuk master dan nomor bisnis untuk transaksi. Response publik untuk kategori, brand, collection, produk dan varian memakai slug/SKU. Admin Detail memperluas projection dengan field input yang telah disanitasi dan timestamp. Array nested maksimum 100, lalu gunakan resource collection.

**Estimasi keranjang.** `AVAILABLE` berarti jumlah dan termin masih tersedia. `PRICE_CHANGED` berarti harga satuan terkini berbeda dari harga saat baris ditambahkan; membaca keranjang atau mengedit jumlah/termin tidak menghapus peringatan. `UNAVAILABLE` berarti baris tidak bisa dibeli sesuai intent dan boleh dihapus. `display_unit_amount` memakai harga terkini bila penawaran masih terlihat, atau harga tersimpan bila tidak. Estimasi menjumlahkan harga penuh (bukan uang muka) × qty untuk baris yang bisa dibeli, sebelum pajak, diskon dan ongkir.
